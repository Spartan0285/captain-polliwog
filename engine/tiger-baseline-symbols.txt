# What Mac OS X 10.4.11 (8S165) exports, for the three libraries where a
# build against the 10.5 SDK can ask for something Tiger has not got.
#
# Taken from a PowerBook G3 with:  scripts/tiger-symbol-check.sh --dump
#
# The reason this file exists: those references are bound lazily, so a
# missing one does not stop the application starting. It starts, renders,
# and disappears on the first page that reaches the code that calls it,
# which reads as "it crashes on YouTube" and sends you looking at YouTube.
# package-webkit.sh checks every Tiger binary against this list.
